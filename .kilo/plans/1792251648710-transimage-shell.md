# TransImage desktop shell

## Goal

Create the cross-platform desktop app TransImage. It opens one raster image and shows it as large as possible under a top bar, without stretching or cropping. It must run on Windows, macOS, and Linux. OpenRouter is a locked dependency only. Do not call the API.

Also add repo-root `AGENTS.md`. Cross-platform support is a key point in that file, not a comment buried in code.

## Decisions

- Platforms: Windows, macOS, and Linux desktops. No mobile, web, or installer targets.
- Packaging: `uv`. Direct deps in `pyproject.toml`. Direct and transitive deps in `uv.lock`. Environment is `.venv`. Do not add `requirements.txt`, `Pipfile`, or Poetry/PDM files.
- Runtime deps: `pillow`, `openrouter`, `python-dotenv`. Dev dep: `pytest`. `tkinter` stays stdlib; do not pip-install it. On Linux, missing Tk is a system package (`python3-tk` or distro equivalent), documented in `AGENTS.md`, not installed by this task.
- Python: `requires-python = ">=3.11"`. Let uv select or install a compatible interpreter.
- Package name `transimage`, window title `TransImage`. Src layout. Launch with `uv run transimage` on every platform. Do not document a PowerShell-only launch path.
- Layout: one reserved header, then a viewport that fills every remaining pixel. No side panel, status bar, or native menu row under the header.
- Header: left text wordmark `TransImage`. Right `File` menu: `Open Image...` and `Exit`. No logo image.
- Shortcut: bind both `<Control-o>` and `<Command-o>`. Accelerator label is `Ctrl+O` on Windows and Linux, `Cmd+O` on macOS (`sys.platform == "darwin"`).
- Font: pick the first installed family from Segoe UI, Helvetica, DejaVu Sans. If none exist, use Tk’s default family at about 16pt bold. Do not require Segoe UI.
- Fit: uniform scale `min(viewport_w / image_w, viewport_h / image_h)`, including scale-up. Center the result. Letterbox with the viewport background. Never crop. Never use different x/y scales.
- One image at a time. A new open replaces the previous image. Store the path with `pathlib.Path`. Remember the path and the full-resolution image for later AI work, but do not send them anywhere.
- `.env` holds `OPENROUTER_API_KEY`. Load it at startup without overriding existing environment variables. Missing file or empty key must not block launch or image open. Never print the key.
- Display-only transforms are allowed: EXIF orientation correction, color-mode conversion for Tk, and resize of a display copy. Do not overwrite the opened file.
- Paths in code and tests use `pathlib`. No drive letters, no hardcoded `\` or `/` joins.

## AGENTS.md

Create `AGENTS.md` at the repo root. Keep it short. Required key points, with cross-platform first and explicit:

- Cross-platform: TransImage must run on Windows, macOS, and Linux. Use `pathlib`. No unguarded `ctypes.windll`, `win32`, AppKit, or X11 calls. Fonts and shortcuts must degrade as specified above. Tk may be a distro package on Linux. Agents must not add OS-specific code without a guard and a fallback.
- Stack: Python, tkinter, Pillow. AI later through the `openrouter` package. Key only in `.env` as `OPENROUTER_API_KEY`. Never commit `.env` or print the key. Do not call OpenRouter until a task asks for it.
- Dependencies: `uv`, `pyproject.toml`, `uv.lock`, and `.venv` only. Never add `requirements.txt`.
- Image rule: open one image; header stays reserved; viewport fills the rest; fit the whole image; never change aspect ratio; never crop or stretch.
- Launch: `uv sync`, then `uv run transimage`. Tests: `uv run pytest`.

Do not add a README. Run instructions for agents live in `AGENTS.md`.

## Out of scope

- OpenRouter requests, model picker, prompts, image generation, or edit/save.
- Drag-and-drop, galleries, undo, themes, installers, and animation of multi-frame GIFs (show the first frame only).
- CI images for macOS or Linux. This machine can execute Windows only. Other platforms are protected by code rules and unit tests, not by running their GUIs here.

## Behavior

Header is a fixed-height bar (about 44px), background `#2b2b2b`. Viewport background `#111111`. Empty viewport shows centered hint text `Open an image`. Default geometry about `1100x720`, minimum about `640x480`.

`fit_image(image_w, image_h, viewport_w, viewport_h) -> (display_w, display_h, offset_x, offset_y)`:

- Non-positive viewport returns zeros.
- `scale = min(viewport_w / image_w, viewport_h / image_h)`.
- Display size is `max(1, round(image * scale))` on each axis, then clamped so it cannot exceed the viewport.
- Offsets center that rectangle in the viewport.

On open:

- `askopenfilename` with PNG, JPEG, GIF, BMP, WEBP, TIFF, plus all files.
- `Image.open`, then `ImageOps.exif_transpose`, then load the first frame.
- Keep that image as the source. Build a display master capped at 4096px on the long side, aspect preserved, so resize stays responsive. Viewport scaling uses the display master only.
- Failure (`UnidentifiedImageError`, `OSError`, `MemoryError`, or any unexpected open error): `showerror` with filename and exception message, no traceback. Keep the previous image.

On viewport `<Configure>`, debounce about 80ms and ignore unchanged sizes. First paint after the window is mapped, because Tk reports a tiny size before layout. Retain the `ImageTk.PhotoImage` on the app object. Use LANCZOS for the display copy. Convert the display copy to `RGBA` only for Tk.

DPI: only when `sys.platform == "win32"`, and only before creating `Tk`, set per-monitor DPI awareness. Ignore failure. macOS and Linux must not touch `ctypes.windll`.

## Failure modes

- uv missing: install it with the official Astral installer for the current OS, then continue. Do not fall back to pip plus `requirements.txt`.
- `.env` absent or key empty: launch normally.
- Corrupt, unsupported, or huge image: dialog, no crash, previous image remains.
- Integer rounding may differ by 1px. That is acceptable. Independent x/y stretch is not.
- `openrouter` import must succeed after sync. Do not construct a client or send a request in tests or at startup.
- Linux without Tk: app import may fail. Document the system package in `AGENTS.md`. Do not add a pip package to fake tkinter.

## Validation

- `AGENTS.md` exists and its cross-platform point names Windows, macOS, and Linux.
- `uv sync` creates `.venv` and `uv.lock` includes `pillow`, `openrouter`, `python-dotenv`, and their transitive packages.
- `uv run pytest` passes, including modifier tests with `sys.platform` patched.
- Source has no unguarded `windll` / `win32` use and no hardcoded backslash paths.
- Fit cases: `100x50` in `200x200` -> `200x100`; `50x100` in `200x200` -> `100x200`; `400x200` in `200x200` -> `200x100`; square image in a square viewport fills both axes. Assert displayed ratio matches source ratio within 1px.
- Manual on this Windows desktop: wide image letterboxes, tall image pillarboxes, small image scales up, resize refits, Ctrl+O works, invalid file does not clear a good image, no network call on launch or open. Do not claim macOS or Linux GUI verification from this machine.

## Implementation order

1. Add `AGENTS.md` with the key points above.
2. Add `pyproject.toml` and `.gitignore`. Use `uv add pillow openrouter python-dotenv` and `uv add --dev pytest` so uv writes the lockfile.
3. Add `.env.example` and create `.env` only when missing.
4. Add `fit.py`, `platform_ui.py`, and tests. Run `uv run pytest`.
5. Add the Tk app and entry point. Wire script `transimage = "transimage.__main__:main"`. Guard the Windows DPI call.
6. Smoke-launch `uv run transimage` and check the manual cases above. Do not commit.
